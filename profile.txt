### 1. Obtenir mon profil
GET {{baseUrl}}/me
Authorization: Bearer {{token}}

### 2. Mettre à jour mon profil
PATCH {{baseUrl}}/me
Authorization: Bearer {{token}}
Content-Type: application/json

{
  "prenom": "Jean",
  "nom": "Dupont",
  "telephone": "+237 123 456 789"
}

### 3. Changer mon mot de passe
POST {{baseUrl}}/me/password
Authorization: Bearer {{token}}
Content-Type: application/json

{
  "ancien_mot_de_passe": "ancienPassword123",
  "nouveau_mot_de_passe": "nouveauPassword456"
}
